# Login Form with Beautiful Design

This project provides a modern login form with a sleek and attractive design. The form includes functionality for user input (username and password), "remember me" functionality, and a link for forgotten passwords. It is styled using **CSS** and enhanced with **Boxicons** for icons.

## 📋 Features

- **Responsive Design**: The form is fully responsive, adapting to various screen sizes.
- **User-friendly Interface**: Clean and intuitive interface with a modern aesthetic.
- **Password and Username Fields**: The form includes input fields for both username and password.
- **Remember Me Option**: Checkbox to keep the user logged in across sessions.
- **Forgot Password Link**: A link to allow users to reset their password if needed.
- **Boxicons Integration**: Icons are used to visually enhance the form for user input fields.
  
## 📁 Files

- **index.html**: Contains the structure and markup for the login form.
- **style.css**: External CSS file responsible for the visual styling of the form.
- **Boxicons**: A web font library for icons, linked externally in the HTML.

## ⚙️ How It Works

### **HTML Structure**

The login form includes:
1. **Username Input**: A text field where users can enter their username.
2. **Password Input**: A password field to enter a secure password.
3. **Remember Me Checkbox**: A checkbox option to allow users to remain logged in.
4. **Forgot Password Link**: A link that users can click if they forget their password.
5. **Login Button**: A button to submit the login form.

### **CSS Styling**

The form is styled to look modern and sleek, with:
- **Centered Layout**: The form is vertically and horizontally centered on the page.
- **Blurry Background**: The background features a stunning image of a sunset landscape, with a blurred effect applied to the form.
- **Box Shadows**: Light box shadows for form elements to create depth.
- **Rounded Corners**: Soft, rounded corners for inputs and buttons to give the form a smooth look.
  
### **Boxicons Integration**

- **User Icon**: Positioned inside the username input field.
- **Lock Icon**: Positioned inside the password input field.

### **Responsive Design**

The form is designed to be responsive and adjust accordingly across devices. The input fields, buttons, and layout resize properly on smaller screens, ensuring a good experience on mobile devices.

## 🚀 How to Use

1. **Clone or Download**: Clone this repository or download the project files.
2. **Link the Files**: Ensure the `style.css` file and Boxicons library are linked correctly in your HTML file.
3. **Open the Form**: Open the `index.html` file in your browser to see the form in action.
4. **Fill Out the Form**: Enter your username and password and click "Login" to simulate a login (currently, there’s no backend functionality).
5. **Styling Customization**: You can further customize the design by modifying the `style.css` file.

## 📍 Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge) that supports HTML5, CSS3, and JavaScript.
- Basic knowledge of HTML, CSS, and JavaScript if you wish to modify or extend the form's functionality.
